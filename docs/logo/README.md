The solomonar learns every secret from one book at the Șolomanța, brings a balaur up from a deep lake with a bridle, and rides it to command the storms. The framework maps that story onto its parts: the book is the specs, the spells are the skills, the dragons are the agents, and the solomonar is the orchestrator who holds the reins.

The mark is that balaur, coiled into an **S** and stitched in cross-stitch. The cross-stitch (*crucea*) is the most common stitch on the Romanian *ie*, and it is a pixel grid centuries older than any screen: the same mark reads as folk embroidery and as 8-bit sprite art. Red thread on cloth with black accents is the classic *ie* palette. The tail ends in an open rhombus, the embroidery motif for balance; the head has an eye, a horn swept back, and fangs. The wordmark is stitched on the same grid.

## Files

| File | Use |
| - | - |
| `lockup.svg` | Mark and stitched wordmark: README, site header. |
| `mark.svg` | The cross-stitch mark alone, 512 × 512: from about 48 px up. |
| `favicon.svg` | Solid squares on a 16 × 16 grid, transparent: browser tabs and small icons. |
| `favicon.ico` · `favicon-16.png` · `favicon-32.png` | The same favicon as bitmaps, pixel-exact at 16 and 32 px. |
| `avatar.svg` · `avatar.png` | Solid squares on cloth, 512 × 512, kept inside the circle that avatars are cropped to. |

The X stitches blur below about 48 px, so the small sizes use solid squares. The favicon grid is the same balaur with two columns and one row taken out of its straight runs, so each stitch lands on exactly one pixel at 16 px and two at 32 px.

The SVG files are self-contained: text is converted to outlines, and the colors follow `prefers-color-scheme` like the diagrams in `docs/images/`. The PNG and ICO files use the light palette.

## Typography

The wordmark is drawn by hand on a 5 × 7 stitch grid. The tagline is [Monaspace Krypton](https://github.com/githubnext/monaspace) (SIL Open Font License), converted to outlines.
