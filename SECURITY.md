# Security policy

## Supported versions

Security fixes go into the latest release. Upgrade to it before you report a problem.

## Report a vulnerability

Do not open a public issue. Report it privately through [GitHub security advisories](https://github.com/madalinpopa/solomonar/security/advisories/new) or by email to contact@madalinpopa.com.

Include the output of `solomonar version`, the affected command, the steps to reproduce, and the impact you expect. You will get an answer within seven days, and the fix is disclosed with credit once a release contains it.
